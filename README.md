
# Bank Management System

A C language college mini project.

## Features
- Create New Bank Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- Display All Accounts
- Search Account Details
- File Handling for Data Storage

## Concepts Used
- Structures
- Functions
- Loops
- Switch Case
- Conditional Statements
- File Handling

## How to Run

Compile:
gcc bank_management.c -o bank

Run:
./bank

## Language
C Programming
